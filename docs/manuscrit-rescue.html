Manuscrit rescue

Manuscrit.AI moved to toolkit.laire.ai/manuscrit. Books and notes written at the old address stay in this browser under the old address. This page downloads them so you can bring them over. It only reads. Nothing is changed or deleted.

Bring them over
  1. Download the backup above.
  2. Open toolkit.laire.ai/manuscrit and sign in.
  3. If you already wrote anything there, download a backup from Settings first. Restoring replaces what is there.
  4. Settings, Backup, Restore, pick the file you downloaded here.
  5. AI keys are never in backups. Add them again in Settings.

Do this on every browser and device you used Manuscrit on. Each one kept its own copy.
